# Reorder worksheet rules

The worksheet uses one line per UPC and active location below its minimum. This lets the owner enter a different quantity for each location. Units sold use the sale location and the last 30 Manila calendar dates, including today. They follow [the sales report rules](0006-sales-report-rules.md) for cancellations and resales.

An order quantity starts blank. The gap to minimum helps the owner choose a quantity. Entries stay in the open worksheet. Excel is the record the owner can keep or send. The export includes every line with a positive quantity. If stock or a minimum changes on an ordered line, the owner must review the current values before export.
