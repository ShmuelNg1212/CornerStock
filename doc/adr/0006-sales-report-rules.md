# Sales report values and cancellations

The sales report uses the catalog price saved when each ball sells. A catalog edit does not change a past sale. The owner can see the report. The price record is separate from the staff activity log.

Sales without a saved price count as units sold. They do not add to the amount. A cancellation removes the sale from its original period. If the ball sells again, the report counts that sale at its own time and location.
